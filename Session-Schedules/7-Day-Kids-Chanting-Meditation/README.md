# 7-Day Kids Chanting & Silent Meditation

Simple daily sessions for children: one short mantra each day + 15 minutes of gentle silent sitting.

- Hub: `index.html`
- Days: `day-01.html` … `day-07.html`

Mantras:
1. Sahana Vavatu
2. Asato Ma Sadgamaya
3. Poornamada (Purnamadah)
4. Maha Mrityunjaya
5. Sarve Bhavantu Sukhinah
6. Shubham Karoti
7. Karpoora Gauram
